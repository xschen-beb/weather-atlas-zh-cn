# 天气与气候地图：完整中文复现包

本项目基于 https://weather.theojaffee.net/ 的公开运行版本，完成界面、图表、天气描述、日期、单位、城市搜索和内置地名的中文化。原始下载时间和文件 SHA256 见 `snapshot-manifest.json`；当前中文运行文件的 SHA256 见 `active-manifest.json`。

## 启动

需要 Python 3。在解压后的项目目录执行：

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

浏览器打开 http://localhost:8080/ 。不要直接双击 `index.html`：ES modules、Web Workers 和数据请求需要 HTTP 服务。

无需安装 npm 包，无需构建。Node.js 22 或更新版本可运行 `node scripts/verify.mjs` 和 `node scripts/verify_zh.mjs`，分别检查科学数据与计算、中文术语与动态文字、双语搜索和日期月份。

## 中文化范围与术语

- 气候筛选、实时天气、预设、筛选条件、图例、逐月统计、图表说明、进度与错误提示均使用中文。
- 4,598 个内置城市和 208 个国家/地区名称有中文译名；保留英文别名以支持中文和英文搜索。
- 地图优先使用底图提供的中文名称，地点详情向地理编码服务请求中文。第三方底图或地理编码服务缺少中文译名时，保留其原始专名，避免编造译名。
- 露点温度与相对湿度、日照时数与昼长、积雪深度与新降雪量分别标明；降水量与降水强度使用相应单位。
- 实时匹配中的降水条件是当前降水强度折算的 24 小时等效量，原始算法并非日累计降水预测，中文提示明确说明。
- 日期和时间使用中文格式；默认使用公制，仍支持切换英制。
- 天气代码依据接口定义区分冻毛毛雨、冻雨、雪粒、雾凇与雷暴伴冰雹。

详细术语依据见 `localization/TERMINOLOGY.md`。

重新生成中文前端：`python3 scripts/localize_zh.py`。脚本从 `upstream/` 中保留的原始快照读取，不依赖 npm 包。翻译词典和地名位于 `localization/`，便于继续修改。当前原站快照与中文版可分别保留，勿直接用下载脚本覆盖正在使用的中文目录。

## 拿到了什么

- `dist/index.html`：发布页面。
- `dist/assets/`：原站压缩 JavaScript、CSS、气候计算 Worker、实时天气 Worker。MapLibre 和相关前端依赖已被打包。
- `dist/data/`：城市列表、海岸线、基础地形、格点和 11 个历史气候变量。
- `scripts/download_snapshot.py`：重新获取公开运行资源的脚本，会解析当时的入口资源名，而不是固定主脚本哈希。
- `scripts/verify.mjs`：直接运行原站气候 Worker 的验证脚本。
- `snapshot-manifest.json`：来源与文件哈希。
- `verification.json`：本次数据和计算验证结果。

## 运行数据与外部服务

历史气候数据加载自副本的 `dist/data/climate/`，不需要向原站请求气候数据。气候与实时天气的计算 Worker、历史数据及筛选阈值保留原值；中文前端和地名经过修改，来源归属说明保留。

以下功能仍需要联网，并沿用原站使用的公共服务：

| 功能 | 服务 |
|---|---|
| 基础地图和字体 | OpenFreeMap / OpenStreetMap |
| 高分辨率地形瓦片 | AWS Terrain Tiles |
| 地点反向地理编码 | Nominatim |
| 全球实时天气 | NOAA GFS 公共 AWS 桶 |
| 美国部分区域天气 | NOAA HRRR 公共 AWS 桶 |
| 地点天气预报 | Open-Meteo |

代码中没有要求填写私有 API 密钥。第三方接口的可用性、跨域设置、使用配额会影响对应功能。这个包不是全离线地图，也没有打包不断更新的全球实时预报。

## 气候统计的具体含义

`meta.json` 将来源标记为 Copernicus/ECMWF ERA5，经 ARCO-ERA5 获取，日指标采用当地太阳时。网站使用 1° × 1° 网格，有效格点为 18,973 个。

每个格点只有 365 个抽样日；取样年份覆盖 2001—2025，按三天一组切换年份。它不是 25 年所有逐日记录的平均。日期概率使用前后 10 天的三角权重平滑，温度按每升高 1 km 降低 6.5°C 作海拔修正。这些原站行为在副本中保留。

## 原始源码恢复范围

这是完整的公开运行快照，并不等于作者原始工程。当前没有找到公开仓库，入口和气候 Worker 未提供 source-map，直接检查对应 `.map` URL 返回 404。

可以阅读、格式化和修改发布后的 JavaScript。仅格式化不会恢复原始变量名、TypeScript 类型、源码目录、注释、测试、依赖锁文件、ERA5 预处理脚本或作者的部署设置。后者需要作者提供原仓库，或者根据本包中可见的行为重新实现。

若后续重建可维护工程，建议逐步提取：页面和筛选状态、地图/WebGL 图层、历史气候数据解码和计算、实时 GRIB 天气数据解码、地理编码和地形。这种重写应保留一个独立的原始快照用于结果对照。

## 部署

把 `dist/` 作为静态网站根目录部署即可。保持 `assets/` 和 `data/` 的相对路径，使用 HTTPS，不要将缺失 `.bin` 或 `.js` 请求改写为 HTML 页面。Web Worker 和 WebGL 需要浏览器支持。

本次运行文件和历史计算已经验证；本环境未执行浏览器/WebGL 的视觉和交互验证，不能将数据检查当成完整浏览器验收。

## 地图

中国外轮廓使用天地图省级行政区划数据（经 GeoJSON.CN 转换），覆盖 34 个省级区域及附属岛屿。南海九个断续线段以及源图中台湾岛东侧的一段均按原始坐标保留，未手绘或替换为线条虚线效果。地图数据与来源记录位于 `localization/maps/`，运行图层位于 `dist/data/china-map.geojson`。

台湾、香港、澳门分别显示为中国台湾省、中国香港特别行政区、中国澳门特别行政区；内置城市、国家代码和逆地理编码返回值采用统一的中国归属。底图对应的独立国家标签及国界线被过滤，原始快照仅作为来源保存在 `upstream/`。地理数据与图层规则已通过程序检查，桌面 Chromium / WebGL 实际渲染也已通过核验，截图与机器报告见 [地图浏览器核验](docs/map-verification/README.md)。本项目不声称已获得地图审图批准。

重建地图图层：安装 `shapely>=2` 后执行 `python3 scripts/build_map.py`，再执行 `python3 scripts/localize_zh.py` 更新入口及文件校验清单。正常运行网站无需安装此依赖。

浏览器自动核验由 `.github/workflows/map-browser-check.yml` 执行，检查地图实际图层、台港澳标签、城市搜索和台北详情，保存截图与运行结果。运行脚本为 `scripts/verify_browser.cjs`；其浏览器依赖只用于测试，正常启动网站不需要安装。
